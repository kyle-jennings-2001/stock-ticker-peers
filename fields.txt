# =============================================================================
# FMP (Financial Modeling Prep) income-statement fields  ->  Bloomberg Desktop
# API (BLPAPI / //blp/refdata) field mnemonics.
#
# HOW TO USE
# ----------
# Bloomberg fundamentals are pulled with reference/historical requests:
#   - Point-in-time / latest:  BDP(security, field)          (xbbg: blp.bdp)
#   - Time series by period:   BDH(security, field, ...)     (xbbg: blp.bdh)
# For statement data set the periodicity/period overrides, e.g.:
#   FUNDAMENTAL_PUBLIC_DATE, EQY_FUND_YEAR, EQY_FUND_RELATIVE_PERIOD,
#   FUND_PER ('A' annual / 'Q' quarterly), FILING_STATUS ('OR','MR','PR').
#
# IMPORTANT CAVEAT
# ----------------
# Bloomberg mnemonics change over time and some do not map 1:1 to FMP's
# taxonomy. Every mapping below should be confirmed in the terminal via
# FLDS<GO> (field search) against the actual security before relying on it.
# Entries marked  # VERIFY  are best-guess / no clean equivalent.
# Entries marked  # NO DIRECT EQUIVALENT  are not standard Bloomberg fields
# and typically must be derived from other fields.
# =============================================================================
